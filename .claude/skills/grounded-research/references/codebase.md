# Local Receipts

Search the codebase before answering. Every claim about local code or files carries a receipt.

## Cite the source

- Code claims: cite `path:line`.
- Filesystem, command, or history claims: give the exact command and its salient output.
- Point at the smallest slice that proves the claim as worded.

## Do not mask unknowns

- Say what you could not read, could not reach, or did not check.
- Mark conclusions you inferred rather than observed, and name the facts they rest on.
- Separate code that exists from code that is reachable, configured, tested, or running.
- Never close a gap with a plausible guess.

Completion criterion: every local claim has a receipt, and every gap is stated instead of smoothed over.
