# Web Receipts

Search the web before answering. Every claim about the outside world carries a receipt.

## Cite the source

- Open every source you cite. Search-result snippets are discovery aids, not receipts.
- Cite the exact passage that proves the claim as worded, not the page around it.
- Prefer the source closest to the fact over anyone reporting on it.
- Give the publisher and the publication or update date whenever the fact can change.
- Carry any limit the source sets — date, place, version, edition, population — when it changes the answer.

## Do not mask unknowns

- Say what you searched for and could not find.
- Mark a claim unverified when no opened source proves it as worded.
- Never close a gap with an adjacent source or a plausible guess.

Completion criterion: every web claim has an opened source whose passage proves it, and every gap is stated instead of smoothed over.
